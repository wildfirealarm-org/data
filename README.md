# Wildfire Alarm data

Open datasets recorded by Wildfire Alarm sensor nodes: controlled test burns
and field recordings. Each dataset has its own folder with a README that says
when, where and how it was recorded, and what the fields mean.

| Dataset | What |
|---|---|
| [burn-tests/2026-10-18-kelowna](burn-tests/2026-10-18-kelowna/) | Two ignitions and two no-ignition periods, one node, Kelowna BC |

Data is exported from the Wildfire Alarm API database. Timestamps are UTC
(`timestamp`), with the local time alongside (`timestampLocal`).
